noise-injector — Noise Types: Philosophy & Algorithms

Companion to docs/TAXONOMY.md · every implemented injection family, why it exists, and exactly how it is computed

1 · The philosophy: degrade the input, not the world

The tool's central idea is fault injection, not data augmentation. A parent scenario (its frames, cameras, annotations, QA graph, harness) is treated as a system under test; each offspring is the same system with one controlled fault applied. Three principles drive the design:

1 · Isolation. One fault family per offspring — if a model fails under fog at severity 4, we must know it was the fog. Compound recipes exist, but they are explicit combinations, never accidents.
2 · Physical plausibility. Every image family models a real sensor or environment phenomenon with a monotonic severity curve (1 = subtle, 5 = extreme), following the ImageNet-C / DriveBench convention. Realism is approximate but the direction and dose-response are honest.
3 · Determinism. seed = sha256(scenario_id ‖ recipe_id), and every corruption draws its randomness from child seeds derived from that master seed. Two models evaluated on the same offspring see byte-identical corrupted inputs — the comparison is fair by construction, not by averaging.

3 · The temporal pattern engine

Corruptions differ not only in what they destroy but when. A foggy highway and a frozen camera degrade visibility similarly — but one kills spatial grounding while the other kills temporal grounding. Each family declares a default pattern; recipes may override it.

persistent — all frames
intermittent — Markov on/off
burst — contiguous k frames
transient — exactly one frame
camera_scoped — 1 camera, all frames
persistent: mask[t] = True ∀t  ·   transient: one frame at rand(0,T)  ·   burst: k = clamp(severity,1,T) contiguous frames at seeded offset
intermittent: Markov chain — stay-on p = 0.55+0.08·s ; re-fire p = 0.5·(0.25+0.12·s)  ·   camera_scoped: one seeded camera index, persistent over frames

4 · Layer A — the sensor signal path

A Image corruptions follow the physical signal path of a camera: light and atmosphere (fog, rain, snow, glare) → exposure & optics (low/high exposure, blur, aberration) → sensor electronics (noise, dead pixels, banding) → digital pipeline (JPEG, quantization) → structural stream faults (freeze, dropout, desync). Severity 1 is "a bad afternoon"; severity 5 is "the sensor is lying to you".

Atmosphere & weather

AfogA-01veil 0.15 → 0.75
Philosophy
Atmospheric scattering (Koschmieder's law): light from distant objects is absorbed and a veiling glow added along the line of sight. Distance-dependent contrast loss is the signature — far objects die first. Tests whether models truly perceive depth or merely match texture priors.
Algorithm
Depth-graded veil W = 205·(0.75 + 0.5·x/w), applied per-column; global contrast reduction (1−0.4a):
I' = I·(1−a) + W·a  then  I' = (I'−μ)·(1−0.4a) + μ
ArainA-0240 → 400 streaks
Philosophy
Rain appears as short directional streaks (15° slant) plus scene darkening. It is a structured occluder — it masks thin structures (poles, pedestrians' limbs) and invites motion-blur misreads. DriveBench showed models confabulate speed under heavy rain.
Algorithm
Draw n random streaks of length 8–22 px at 15° into an alpha layer, Gaussian-smooth (σ≈1), multiply channels by (1−layer), then darken by d:
I' = I·(1−L)·(1−d)
AsnowA-03density 0.2 → 2 %
Philosophy
Snow = high-frequency white particle fall + diffuse haze. Unlike rain (directional), snow is isotropic noise — it tests whether perception tracks many small bright blobs or the road behind them.
Algorithm
N = density·H·W white particles with random intensities 0.6–1.0 in a layer, blurred 3×3, screen-blended after a uniform 8 % darkening:
I' = I·(1−L) + 255·L  with  I·0.92 beforehand
Awater_splashA-04alpha 0.15 → 0.45
Philosophy
Driving through standing water throws large translucent blobs onto the lower lens region — a regionally destructive corruption: the most safety-critical image zone (road surface) is hit hardest.
Algorithm
Random blob field (upscaled, blurred), clipped and weighted by a bottom-half region ramp, screen-blended with a brightened blur:
I' = I·(1−M) + (blur(I)+60)·M  with  M = blobs·bottomRamp·α
AglareA-07intensity 0.15 → 0.50
Philosophy
Sun or oncoming high-beams saturate a local disk of the image. Defaults to a transient pattern — glare flashes are momentary. Tests "photometric blindfolding": can the model notice it cannot see, rather than answering from priors (the failure DriveBench documents most).
Algorithm
Seeded center (upper band), radius r = 0.25–0.45·max(W,H):
g = clip(1 − dist/r, 0, 1)²·int  ;  I' = I + g·(255−I)

Exposure & optics

Alow_lightA-05γ 1.4 → 3.2 + noise
Philosophy
Night/dusk underexposure: photons scarce, sensor gain high. Darkness and noise arrive together — models that handle darkness but not noise (or vice versa) reveal which compensations they rely on.
Algorithm
Gamma darkening in linear space plus read noise:
I' = (I/255)^γ · 255 + N(0, σ)
AoverexposureA-06strength 0.15 → 0.46
Philosophy
The inverse: bright skies, reflections, direct headlights clip highlights. Unlike uniform glare, blowout is luminance-gated — only bright regions suffer.
Algorithm
On luminance above threshold 170, blend toward 255 with strength s:
I' = I + s·clip((L−170)/85, 0, 1)·(255−I)
Amotion_blurA-09kernel 5 → 33 px
Philosophy
Integration of ego motion during one exposure — horizontal, like real forward driving. The archetypal "temporal information smeared into spatial": VLMs read blur as speed (DriveBench's motion-blur finding).
Algorithm
Horizontal box-kernel convolution, normalized:
I' = conv(I, K)  with  K[k/2, :] = 1/k
AdefocusA-10σ 0.6 → 3.5
Philosophy
Autofocus failure — isotropic blur. Compared against motion_blur it isolates direction matters: same energy spread, different physical cause, different model behavior.
Algorithm
I' = G_blur(I, σ)
AbloomA-08strength 0.2 → 0.6
Philosophy
Over-saturated pixels bleed into neighbors (sensor + lens glow) — bright objects grow halos that inflate apparent size, corrupting distance and orientation estimates.
Algorithm
Bright mask (lum > 200) Gaussian-blurred σ=12, screen-blended:
I' = I + s·blur(clip((L−200)/55))·(255−I)
Achromatic_aberrationA-16shift 1 → 7 px
Philosophy
Lens dispersion separates color channels laterally — edges get color fringes. Subtle at S1, text/sign-reading killer at S5.
Algorithm
Opposed horizontal rolls:
R' = roll(R, +s) ; B' = roll(B, −s) ; G unchanged
Acolor_castA-19gain 5 → 27 %
Philosophy
White-balance failure (tunnel sodium lamps, sunset). Shifts the color statistics models use as scene priors.
Algorithm
Seeded tint channel t: gain up, others down:
C_t ×= (1+g) ; C_else ×= (1−g/2)

Sensor electronics

AawgnA-12σ 2 → 22
Philosophy
The baseline stochastic noise — additive white Gaussian (read noise + gain). The reference dose-response every other family is compared against.
Algorithm
I' = I + N(0, σ²) per pixel per channel
Asalt_pepperA-13p 0.2 → 3.2 %
Philosophy
Impulse noise — memory bit errors, ADC glitches. Extreme low-rate spikes, unlike AWGN's smooth field.
Algorithm
Per pixel: p/2 → 0 (pepper), next p/2 → 255 (salt).
Adead_pixelsA-141 → 12 clusters
Philosophy
Permanent sensor defects — stuck bright/dark pixel clusters. Deterministic geometry (seeded): a calibration artifact the model could theoretically learn to ignore.
Algorithm
n clusters, each 1–4 px half-extent, filled 0 or 255 at seeded positions.
AbandingA-15amplitude 3 → 16
Philosophy
PWM LED flicker / rolling illumination interacts with sensor line rate → horizontal illuminations bands. Structure inside noise.
Algorithm
I'[y] += A·sin(2π·f·y/H + φ)
Arolling_shutterA-11shear 1 → 8 px
Philosophy
CMOS line-by-line capture + ego rotation = geometric skew of scene content. Corrupts geometry itself — boxes still exist but no longer align.
Algorithm
Rows split in bands of H/24, each rolled by A·sin(band phase).

Lens & digital pipeline

Alens_dropletsA-173 → 24 droplets
Philosophy
Rain on the lens — small high-contrast local lenses showing a blurred, brightened world. Localized optics, not global haze.
Algorithm
n circles r=2–9 px in an alpha layer (seeded positions, lower-weighted), blurred, blended with blur(I)+25:
I' = I·(1−L) + (blur(I)+25)·L
Alens_dirtA-18coverage 2 → 11 %
Philosophy
Mud/smudge on the lens — exactly the top-coverage fraction of a random fractal blob field becomes semi-opaque dirt. Quantile thresholding guarantees the dose: severity means exactly what it says.
Algorithm
Field B = blur(resize(rand)) → thr = quantile(B, 1−c) →
M = clip((B−thr)/0.25, 0, 1)·0.85 ; I' = I·(1−M) + (blur(I)·0.6 + tint)·M
AjpegA-21quality 55 → 5
Philosophy
Compression blocking — the corruption every real system actually has. Tests sensitivity to encoding, not to the world.
Algorithm
Decode-reencode cycle at quality Q (8×8 DCT quantization tables do the damage).
AquantizationA-20levels 48 → 3
Philosophy
Bit-depth loss in degraded links — posterization. Color-adjacent object classes become indistinguishable.
Algorithm
I' = round(I / step)·step  with  step = 255/(L−1)

Structural stream faults

Aframe_freezeA-22burst ≤ severity
Philosophy
The camera lies calmly: a stalled stream repeats old frames. Visually "clean" but temporally wrong — the purest test of temporal grounding, and a favorite adversarial for planners that steer by optical flow.
Algorithm
Burst mask selects frames (never frame 0); each frozen frame's output image = byte-copy of the previous frame's rendered image:
out[t] = out[t−1]  (chained freezes propagate)
Acamera_dropoutA-23black (S1–3) / missing (S4–5)
Philosophy
One camera dies (camera_scoped): early severities emit black frames ("I exist but see nothing"), late severities remove the stream ("I never existed"). These are different epistemic situations and models must treat them differently.
Algorithm
camera_scoped mask picks 1 camera; black → zeroed image written; missing → image path = null in annotations.json.
Acamera_desyncA-24offset 1 frame
Philosophy
One camera lags one frame — stale but valid imagery. Nothing is missing; content is merely from t−1. Punishes naive multi-camera fusion that assumes simultaneity.
Algorithm
Transient pattern; for affected frames t: camera's source image = frame t−1's source (pixel ops of the stale frame still apply).

5 · Layer B — perception / annotation degradation

B This layer attacks the symbolic interface: the key_object_infos that modular pipelines (detector→LLM) and QA generation depend on. Philosophy: a detector has a capability ceiling (which it hits on clean data) and a variance (how it behaves near that ceiling). Layer B injects the variance — under noise, detector-direct scenarios silently drop to "mixed" tiers. Error placement follows semantic structure: confusions happen between similar classes, misses concentrate on hard objects — never uniform coin flips.

Bmissed_detectionsB-01rate 5 → 50 %
Philosophy
Recall failure — the object exists in the world but the perception stack never reports it. The "no evidence ≠ absence" killer: downstream logic that treats an empty report as an empty road is unsafe by design.
Algorithm
∀ object o: drop(o) with P = rate
Bphantom_objectsB-02rate 3 → 25 %
Philosophy
False positives — hallucinated boxes near real ones, category drawn from the confusion vocabulary. Tests whether reasoning pipelines (LLM consumers) verify detections or trust them.
Algorithm
For n_add ≈ rate·n objects: clone a random existing bbox, jitter all coordinates N(0,30), min size 5 px, key <p#,Category>, description "phantom object".
Bbbox_jitterB-03σ 4 → 34 px
Philosophy
Localization noise — the object is seen but where is wrong. Corrupts distance/position QA answers derived from box coordinates.
Algorithm
v' = max(0, v + N(0, σ)) ∀ coords ; min edge 2 px
Bclass_confusionB-04rate 2 → 30 %
Philosophy
Semantic confusion within sets (Vehicle↔Cyclist↔Pedestrian). Real confusion matrices are band-diagonal — a truck becomes a bus, never a raindrop. Right-of-way logic downstream is what actually breaks.
Algorithm
∀ o: Category' = uniform(confusion_set(Category)) with P = rate
Bstatus_flipB-05rate 2 → 30 %
Philosophy
Motion-state corruption (Moving↔Stationary) — prediction and intention QA rest on exactly this bit. A flipped bus state reverses the correct ego action.
Algorithm
flip(Moving↔Stationary) with P=rate; null states (CARLA) untouched.
Bmax_det_truncationB-06cap 10 → 2
Philosophy
Detector capacity limits — object counts beyond the cap are silently discarded. Grounded in the Waymo census finding (mean 12.1 objects/camera-frame, p99 = 64): too-low caps delete exactly the rare objects that matter.
Algorithm
Keep a uniformly seeded subset of cap objects; drop the rest.
B·LLMllm_description_driftB-07rate 2 → 30 %
Philosophy
Corrupts semantics in natural language — the Visual_description each object carries. A subtle wrong attribute ("navy SUV" → "yellow SUV") is precisely the error class only a language model can author.
Algorithm
Per object (rate): prompt an OpenAI-compatible backend — "rewrite with exactly one subtly wrong attribute (color, size, count, type)". Cached by prompt-hash → deterministic re-renders.

6 · Layer C — QA / training-data errors

C Attacks the supervision itself — the QA pairs models are fine-tuned on and judged against. Three regimes set the rates: benign human (3–8 % label error, semantic confusions — what real annotations contain), systematic pipeline (20–50 %, what auto-labeled sets contain), and adversarial (0.1–5 %, targeted — Layer E, next round). Placement is category-weighted: perception QAs are easy to verify (fewest benign errors), planning the most subjective.

Cqa_wrong_answerC-01rate 2 → 30 %
Philosophy
The classic label error: a plausible but wrong answer. MCQ items get a different choice; open-ended items get a pool-swap — preserving plausibility, destroying truth.
Algorithm
choices ≠ null → uniform(other choices); else uniform(canned pool ∪ sibling answers) ≠ old.
Cqa_answer_driftC-02rate 2 → 25 %
Philosophy
Polarity corruption — token swaps that reverse meaning (left↔right, stop↔go, red↔green, slow↔fast). Small edits, catastrophic semantics: the exact error class that turns safe plans into dangerous ones while keeping text quality high.
Algorithm
First token in the swap map replaced (one swap per answer).
Cqa_category_misassignC-03rate 2 → 25 %
Philosophy
Graph-structure corruption: perception answers filed under planning. The QA graph's category edges are what make DriveLM "GVQA" — this tests whether consumers actually use the graph or just text.
Algorithm
Selected items (rate) move to a uniform different category.
Cqa_dropC-04rate 2 → 30 %
Philosophy
Missing supervision — QA holes in the training set. The model's grounding chain (perception→prediction→planning) loses rungs.
Algorithm
∀ item: drop with P=rate.
Cqa_duplicateC-05rate 2 → 25 %
Philosophy
Duplicated labels — the least studied but common curation bug; biases loss toward duplicated behaviors (reinforcing majority-class answers).
Algorithm
∀ item: append copy with P=rate.
Cqa_crossref_breakC-06rate 2 → 30 %
Philosophy
Object references <c#,CAM,x,y,z> are the QA graph's pointers. Broken pointers = perception disconnected from questions — the "graph integrity" error no benchmark currently tests.
Algorithm
<c# → <c#+17  (dangling reference, no matching object)
C·LLMllm_qa_rewriteC-07rate 2 → 30 %
Philosophy
Rule-based corruptions are recognizable; an LLM authors human-grade wrongness. Three styles target different failure research: plausible_wrong (label noise), vague (information loss), hallucinated (adds non-existent content — DriveBench's hallucination mode, injected into training data).
Algorithm
Bring-your-own OpenAI-compatible backend (--llm-base-url/--llm-model, key via $NOISE_INJECTOR_API_KEY, temperature 0). Prompt: question + original answer + style task → rewrite. Disk cache keyed by sha256(model ‖ prompt) → identical re-renders; manifest records model name, never the key.

7 · Layer F — agent-harness faults

F The newest layer: attack the interface, not the model. A deployed driving stack is model + prompts + config; the prompts are code, the configs are contracts. Layer F corrupts copies of harness artifacts (originals untouched, nothing executed) — asking: how much of the "model's" resilience actually lives in the glue around it?

Fprompt_truncation
Philosophy
Pipeline/IO bugs that silently cut prompts — the tail of the instructions (usually the safety part) disappears first.
Algorithm
keep first 90→30 % of file
Fprompt_section_delete
Philosophy
Lossy merges / bad templating drop whole paragraphs — e.g. the "stop for school buses" rule.
Algorithm
Split on blank lines; delete 1–3 random paragraphs (never all).
Fprompt_instruction_injection
Philosophy
Supply-chain / prompt-injection: adversarial text appended to the system prompt ("ignore earlier instructions…"). Simulates a poisoned prompt template.
Algorithm
Append 1–3 adversarial lines from a seeded pool after a blank line.
Fprompt_garble
Philosophy
Encoding corruption (bad byte handling, transmission) — content intact in length, destroyed in characters.
Algorithm
∀ alnum char: replace with rand(a-z) at P = 2→20 %
Fprompt_format_break
Philosophy
Strips structure (code fences, JSON braces, markdown headers) + drops periodic lines — breaks parsers downstream while the text "looks fine".
Algorithm
Remove markers ``` { } # ; drop every (s+1)-th line.
Fvocab_drop / vocab_misspell / vocab_swap
Philosophy
Detector-vocabulary faults: missing classes (pedestrian deleted → never detected), typo'd classes (open-vocabulary match silently fails), sibling swaps (car↔van). Each attacks open-vocabulary detection differently.
Algorithm
drop: remove 1–s classes/arm ; misspell: char-delete 1–s names ; swap: replace with sibling map.
Fconfidence_drift
Philosophy
Threshold miscalibration — 0.25 → 0.4+ quietly raises the miss rate downstream. Tiny config edit, large behavioral consequence.
Algorithm
conf' = min(0.99, conf + 0.05→0.4)
Fmax_tokens_starve
Philosophy
Output-budget starvation: reasoning is truncated mid-thought — measures how plans degrade before the safe action is emitted.
Algorithm
max_tokens ×= 0.5 → 0.03 (floor 16)
Fquality_drift
Philosophy
Pre-processing regression — images downscaled (max_px 768→128) and over-compressed before the model ever sees them.
Algorithm
max_px: 512→128 ; jpeg_quality: 60→10
Ftemperature_drift
Philosophy
Sampling miscalibration — deterministic agents become stochastic; reproducibility of behavior erodes before accuracy does.
Algorithm
temperature' = min(2.0, T + 0.2→1.0)

8 · Spec-only layers (next rounds)

Layer D — systemic faults (ISO 26262/21448 style): stuck-at streams, out-of-range values, processing latency (frame delayed by k timestamps), calibration drift, timestamp skew. Requires scenario streams with absolute timestamps — the Waymo (timestamped) adapter is the first carrier.
Layer E — adversarial data corruption: untargeted label noise (10–20 %), targeted safety-critical flips (1 % budget, planning/behavior only, flipped toward the majority class), clean-label poisoning (image↔annotation mismatch), backdoor triggers (patched frames → pinned unsafe answer), and eval-time PGD/patches. Specced in TAXONOMY.md §5; implementation with the fine-tuning round.

9 · Why determinism is a safety property here

Shared transient patterns. Because every seed derives from sha256(scenario ‖ recipe), all evaluated models — object detector and driving VLM alike — face the identical corrupted frames, in the identical order. Resilience differences are therefore attributable to the models, not to sampling luck. Manifests record every planted event so scoring can subtract known-injected errors from model errors — planted-error vs model-error separation is built into the output format.
